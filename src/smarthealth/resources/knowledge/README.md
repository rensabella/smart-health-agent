**SmartHealth 受控知识语料 v1.0**

[corpus.json](./corpus.json) 包含 8 篇短中文参考笔记，用于检索心率、EDA、EEG、活动背景、睡眠指标和可穿戴设备测量限制。原始来源均为官方机构、设备厂商文档或原始研究论文；核对日期为 **2026-09-08**。具体 URL、页面日期、章节和使用范围见 [来源说明](https://github.com/rensabella/smart-health-agent/blob/main/docs/rag_sources.md)。

每篇笔记明确分为“来源事实”和“项目适用边界”。前者是对所列来源的有限事实转述；后者来自本项目的数据协议和模型范围，不能被归因为来源作者的结论。正文保留 `heart_rate`、HR、EDA、EEG、PPG、`activity`、`sleep_quality` 等检索词，支持中英文问题与特征名称的对应。

知识库没有患者记录、原始传感器数据、疾病问答或治疗指令，没有复制整篇论文、网页或图片。资料中的真实生理背景不改变当前模型仅用合成数据训练的事实。检索到某个影响因素，只能提供解释背景，不能据此认定某位用户发生了该因素，更不能替代医学诊断或临床验证。

文件职责如下：

| 文件 | 内容 |
|---|---|
| `corpus.json` | 索引输入：知识版本、精确来源 URL 白名单及文档 |
| `manifest.json` | 本地语料文件 SHA-256、各文档正文和来源元数据哈希 |
| `README.md` | 语料范围、格式与维护规则 |

每个文档包含这些字段：

| 字段 | 含义 |
|---|---|
| `source.id` | 稳定的来源标识，不由用户或模型生成 |
| `source.title` / `url` / `source_type` | 原始标题、精确 HTTPS URL、来源类别 |
| `locator` | 用于人工复核的章节或页面位置 |
| `content` | 本地编写的简短中文笔记 |
| `content_hash` | `SHA-256(content.encode("utf-8"))` |
| `accessed_at` | 本次核对来源的日期，不等同于来源发布日期 |
| `rights` | 有限转述、归属或来源许可说明 |

`allowed_source_urls` 与文档 URL 一一对应；它是可纳入语料的来源范围，不是请求时自动抓取网页的指令。模型提出的新 URL、用户上传文件和历史记忆不进入此白名单。

`manifest.json` 中的 `corpus_file_sha256` 对 `corpus.json` 的实际文件字节计算，因而包含排版变化。`source_metadata_sha256` 对文档中的 `source`、`locator`、`accessed_at`、`rights` 四项组成的对象计算，使用 UTF-8、`ensure_ascii=False`、`sort_keys=True` 和紧凑 JSON 分隔符。**这些哈希描述本地笔记与归属信息，不是远程网页或论文原文的哈希。** 本仓库未保存原始网页快照。

更新来源时，应重新核对具体章节，保持来源事实与本项目结论的区分，再更新正文、核对日期和哈希；内容发布变化同时更新 `knowledge_version`，并重新构建索引。保留来源原有权利说明，不能因为内容进入代码仓库就宣称取得原网页或图片的额外授权。论文条目的转述保留作者署名、论文链接、许可链接和改写说明。

该集合是可检查的初始语料，不是完整的健康指南或持续更新的医学知识库。未覆盖的问题应返回证据不足，不能用相似度分数代替资料覆盖或证据支持程度。
