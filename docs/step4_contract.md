# Step 4 implementation contract

The existing Skill Registry and AnalysisService stay stable. This phase implements an actual decision/observation loop and the execution harness minimum; no Router, Memory, RAG, Writer or semantic Safety placeholder. Explicit `objective` and `entry_agent` select the task contract, not natural-language routing.

Shared schemas live in `app/agents/contracts.py` (root owns). Decision actions are `CallSkillAction`, `DelegateAction`, `FinishAction`, `RequestInputAction`, validated via `ACTION_ADAPTER`. `DecisionRequest` is a bounded state snapshot with typed observations, registered callable schemas and server-produced refs. No raw CSV or dataframes enter it. Runtime owns authoritative state and revalidates all decisions even model-constructed ones. Public progress/trace records controlled action summaries, references and safe errors, never raw query, delegation text, provider response text or hidden reasoning.

Backend owner: implement `app/agents/backends.py`, `app/agents/prompts.py`, `tests/test_agent_backends.py`. `DecisionBackend` exposes `mode: str` (`disabled`, `scripted`, `live`), `async decide(request: DecisionRequest) -> DecisionReply`, `async aclose()`. `DisabledDecisionBackend` raises safe `SkillError('backend_unavailable',...)`. `ScriptedDecisionBackend` takes a callable of DecisionRequest -> action/dict/DecisionReply (can await) for deterministic tests; explicitly no real LLM, no shared cursor across runs. `OpenAICompatibleBackend(base_url,api_key,model,timeout_seconds=30,transport=None)` uses httpx async client, one POST chat/completions per decide, no automatic retries. Tools consist of request.tools plus control tools `finish`, `request_input`, and planner-only `delegate`; exact one tool call required. Map returned call to typed action, reject free text/refusal/multiple calls/invalid JSON, bound response bytes/context, safe error codes and reported token usage. URL admin-only HTTPS or loopback HTTP; no redirects or secret logging. `backend_from_env()` defaults disabled; HEALTH_AGENT_BACKEND=openai_compatible requires HEALTH_LLM_BASE_URL, HEALTH_LLM_API_KEY, HEALTH_LLM_MODEL. Do not auto-enable scripted in API. Root moves httpx to runtime deps. Existing official OpenAI docs checked by root: https://developers.openai.com/api/docs/guides/function-calling and https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create . User informed of OpenAI Docs skill. No real credentials or paid external calls.

Storage owner: implement `app/agents/events.py`, `tests/test_agent_events.py`. `RunEventStore(directory: Path | None=None, max_events=512,max_runs=128)` owns per-run bounded deque/sequence, optional privacy-safe JSONL journal. Interface sync `register(run_id, *, owner_id, session_id, metadata: dict)`, `append(run_id,event: str, *,agent=None,step_id=None,parent_step_id=None,data=None)->RunEvent`, `get_events(run_id, *,owner_id,session_id,after_id=0)->list[RunEvent]`, `latest_id(run_id)->int`, `forget(run_id)`, `recover()->list[dict]`. All reads enforce owner/session; unknown404 `run_not_found`, crossscope403. Replay rejects future/negative ID (invalid_event_cursor), and expired cursor behind deque floor (replay_unavailable). A new connection after_id=0 also reports gap if history evicted. Optional journal: dir0700, per-run file0600, metadata header with owner/session/input_version/request_id/backend_mode/objective/entry_agent/created_at/parent_run_id only (NEVER query/raw data/final result); records RunEvent models only. `recover()` reads bounded journal files, restores metadata and event sequences, identifies last run terminal state or marks interrupted state failed with `process_restarted` event, returns metadata+status+error_code for root to create read-only snapshots. Completed old runs cannot restore raw final results; indicate result unavailable but keep terminal state/traces. Journal IO failures raise safe `trace_unavailable`, no swallowing. Lock for append/read concurrency, memory limit and retention cleanup (default 7 days) and unknown files untouched. Child agent may refine interface but must notify root early.

Root owns `app/agents/runtime.py`, `app/api/agent.py`, main integration, runtime/API tests, docs/examples. Runtime creates one task per run, supports idempotency scoped to owner+key+request digest, same-session active run conflict, bounded active/retained runs, snapshot/event/cancel read ownership, max decisions/LLM calls/Skill calls/delegations/deadline and cancellation. Planner can delegate one level to data_analysis; all share global budgets and observe current authoritative outputs. Only server-produced refs from this run can be selected (uploads initially owned). Finish data_analysis requires a matching analysis_ref and optional plot results; it publishes deterministic tool-derived JSON, never LLM free text. score_definition uses a fixed model-card statement. health_report finish is blocked until actual RAG/Writer/Safety in Step 8; cannot finish with another kind to downgrade it. Missing inputs return awaiting_input. HTTP endpoints create/get/cancel/events/trace; SSE replays from Last-Event-ID, disconnect only stops subscription, terminal events close stream. API context single-owner local_demo remains until later auth layer.
