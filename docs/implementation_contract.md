# Step 3 integration contracts

This file fixes interfaces between the Registry and independently implemented domain services. Step 3 implements the six data Skills and the real underlying Tool. No Agent Loop, RAG, or report-generation placeholders are registered.

- Project imports: `app.*` for domain/core, `skills.*` for skill adapters. Run commands from this project directory.
- `app.core.errors.SkillError(code: str, message: str)` is a safe domain exception. Messages must not contain input data, paths, credentials, or exception reprs.
- `app.core.context.SkillContext` is a frozen dataclass with `owner_id`, `session_id`, `run_id`, `input_version`, `allowed_skills: frozenset[str]`, `deadline: float` (time.monotonic), `budget: CallBudget`, `cancelled: threading.Event`. `check_active()` raises SkillError if cancelled or deadline exceeded. `CallBudget(max_calls=...)` atomically reserves actual dispatches.
- `app.core.artifacts.ArtifactStore(ttl_seconds=3600, max_bytes=67108864, max_items=256)` offers `put(value, *, kind, context, source_ref=None, schema_version='1.0') -> str`, `get(ref, *, kind, context) -> Any`, `delete(ref, *, context)`, `clear()`. Values are copied on put/get, references are opaque, owner/session/input_version and expiration are enforced. Artifacts remain in memory. Context must be active when committing writes.
- `skills.base_skill.SkillModel` is Pydantic BaseModel with strict validation, extra='forbid', allow_inf_nan=False, revalidate_instances='always'.
- `BaseSkill[InputModel, OutputModel]` has class attributes `name`, `description`, `version='1.0'`, `input_schema`, `output_schema`, `timeout_seconds=30.0`; `execute(input: InputModel, context: SkillContext) -> OutputModel` can be sync or async. Domain Skills should be synchronous, injected with services/store at construction. They return a concrete OutputModel and raise SkillError for known failures.
- `skills.registry.SkillRegistry(max_concurrency=4, trace_sink=None)` exposes `register(skill)`, `describe(allowed_skills=None)` (schema manifest list), `tool_definitions(allowed_skills)` (function-calling schema), async `execute(name, payload, context) -> SkillResult`, async `aclose()`. SkillResult has `status` ('success'/'error'), `data` (JSON dict or None), `error` (code/message or None), `warnings`, `skill`, `version`, `run_id`, `call_id`, `latency_ms`. Direct calls to skill.execute are available for isolated unit tests; application calls go through Registry.
- Every registered Skill receives a fresh child context; a timeout cancels that child without allowing late artifact commits. Bounded worker slots remain occupied until timed-out synchronous computation actually exits.

Domain interfaces:

- `app.pipeline.preprocess.parse_csv(content: bytes) -> pandas.DataFrame`: validate header/numerics/time/single-session; no training labels or arbitrary extra fields accepted online. `inspect_data(frame) -> dict` returns a JSON-safe quality report. `preprocess(frame) -> tuple[list[pd.DataFrame], dict]`: clean and create 30-row (1 Hz) non-overlapping windows, quality errors are SkillError. Explicit tail/short-gap behavior.
- `app.pipeline.feature_engineering.extract_features(windows: list[pd.DataFrame]) -> pd.DataFrame`: fixed versioned feature names/order; immutable FEATURE_NAMES and FEATURE_SCHEMA_VERSION constants.
- `app.models.model_loader.load_model(bundle_dir: str | Path) -> BasePredictor`: trusted local model bundle only; load once at application startup. Predictor supplies `.metadata` JSON dict, `.predict(features: DataFrame) -> dict` with `prediction`, `risk_score`, `important_features`, `model`, `aggregation`, `window_count`, `anomalous_ratio`, `highest_risk_window`, `window_predictions` and `.explain(features: DataFrame, *, top_k=5) -> dict` (global importance and highest-risk-window evidence with clear units/scope). `risk_level` may be included. `metadata` contains feature schema, model version and task scope.
- `app.visualization.plots.render_plots(windows, prediction: dict, explanation: dict, plot_types: list[str]) -> list[dict]`: each item has `kind`, `mime_type='image/png'`, `content: bytes`. Supported kinds: `signals`, `risk`, `importance`. Use noninteractive Figure API and bounded/serialized rendering.

`app.schemas.response` supplies the shared public contracts. `AnalysisService` retains server-produced lineage between model and feature artifacts. HTTP handlers and Skill adapters use the same domain interfaces. Registration and application execution remain explicit; no dynamic filesystem plugin discovery or client-selected model path is supported.
